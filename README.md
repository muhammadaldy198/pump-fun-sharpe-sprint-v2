A paper-trading bot for pump.fun's Sharpe Sprint, tuned for hourly Sharpe rather than raw PnL. A judged-momentum runner: judgement at age 45 slots (real reserves 15–80 SOL, 1.5–8x from creation, at least 18 buyers, 10 buys, 3 SOL net flow, ownership gates when 5+ holders are recorded), staged adds only on real strength (+10% steps to a 0.90 SOL cap), 70% banked at 2x and 50% of the rest at 4x, −15% stop, trailing exit, and a 45-minute hour-end lock that sells 100% of any position at +1% or better — so hourly equity marks capture the gain instead of giving it back. Dev (2–3 Nov 2026): +1.86 SOL, Sharpe 0.455, max drawdown 4.7%, 75 coins traded.

## Run it

```sh
node main.ts
```
